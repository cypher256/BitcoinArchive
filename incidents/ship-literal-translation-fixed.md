# ship の直訳「出荷」誤用の是正

**関連ルール:** I.9 直訳禁止(典型パターン表)
**日付:** 2026-06-27

`ship the codebase / ship a fix / ship v0.x / an idea gets shipped`のようなソフト・コード文脈の`ship`を「出荷した」と直訳していた箇所を、アーカイブ横断19ファイル約70箇所で「公開した・世に出した」「リリースした」等に是正した(コミット`225d1d938`)。

対策: `ship`の例外(温存):物理ハードウェア・物品に対する「出荷」(ASIC・マイニング機器等)は正しい自然な日本語であり、そのまま残す。ソフト/コード文脈か物理文脈かで判定する。
