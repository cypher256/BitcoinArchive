# 0522一括移行による重複qNレガシーの救済

**関連ルール:** I.4 継続引用の話者タグ(自動描画)
**日付:** 0522一括移行(2026年5月22日頃)

0522一括移行が、1通のメールから複数箇所引用する際に本来1つで済むはずのqNを引用ブロックごとに別々発行してしまったレガシーエントリーが存在する(同一personかつ同一sourceEntryIdがquotes[]内で重複)。`remark-quote-blocks`の描画側で論理ソース単位に束ねて救済する設計になっている。

対策: 「論理ソース」とは(正規化した人物, sourceEntryId)の組。同じ1通を指す複数のqNは1ソースと数え、描画側で継続タグに降格させる。
